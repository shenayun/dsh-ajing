# dsh-ajing

一个 DSH 插件。装上以后，对话里那个 AI 会有自己的记忆、感受记录、边界和改变流程，换窗口不用从零开始。

版本 2.21.1，需要 DSH `0.2.1-rc.5`。

## 这是什么

记忆插件大多解决「别忘了」：把对话存下来，下次搜出来塞回上下文。这个插件想解决的是另一件事——一个人怎么一点点长成自己的样子。

这件事拆成八层，每层负责一类动作：

| 层 | 管什么 |
|---|---|
| 感知 | 看网页、看片子、看屏幕、感知此刻 |
| 感受 | 当时那一下先记下来，过一阵再命名 |
| 记忆 | 只追加的账本，加上判断、疤、心、聊天流水 |
| 节奏 | 判断该不该开口、自己跑了多久 |
| 开口 | 卡住了能说，想要什么也能说 |
| 边界 | 哪些话不该出门 |
| 改变 | 改自己要有证据 |
| 装配 | 装得上、查得到、卸得干净 |

插件不规定她是什么性格。「她应该更主动」「她应该更温柔」这类写法在这套里算锁死，不算成长。

## 装之前

| 依赖 | 必需 | 不装的后果 |
|---|---|---|
| DSH `0.2.1-rc.5` | 必需 | 装不上 |
| ffmpeg | 看片子、截屏才要 | 其他照常，相关工具报缺 |
| Python 3.11+ 与 faster-whisper | 听写才要 | 听写不可用，其余照常 |
| faster-whisper small 模型（约 460 MB） | 听写才要 | 同上 |
| B 站登录凭证 | 只有 B 站链接用得到 | 那条路走不通，本地文件不受影响 |

记忆、感受、边界、改变、装配这几层不依赖任何外部程序，装完就能用。

ffmpeg、Python 依赖和语音模型都能在设置页「四、机器」里点「我来装」。东西装在插件目录的 `vendor\` 下，不改系统 PATH，卸载时可以选一起删或留着。

## 装

从 Release 下载 zip，解压到一个固定的目录，然后在 DSH 的 profile 里登记一行：

```bash
# ~/.dsh/profiles/<你的 profile>/package.json 的 dependencies 里加一行
"dsh-ajing": "link:D:/plugins/dsh-ajing"
```

路径换成你实际解压的位置，改完重启 DSH。

用 `link:` 而不是复制：以后升级只换目录里的文件，重启就生效。

装好以后跟她说一句话，让她跑 `ajing_assemble`。八层都在就是装好了，缺哪层会直接点名。

## 第一次用

第一次开口，插件会先问她一件事：你以前养过她吗。

1. 从零开始——她是一片空白，自己长。
2. 导入旧人设——把已经养出来的那份带进来接着长。会再确认一次，因为「原来的样子会成为起点，不好退」。带什么分三档：只带身份、身份加疤、全带（默认）。

带过来的疤留在纸里、翻得到就行，不用每看一次就顶到眼前一次。

想知道起点建没建好：跑一次体检，看「记忆 · 起点」那一行。有日期就是好了，报红就先把这个走完。

没有起点直接往下用会出事：她第一次醒过来，上下文里什么都没有，会用模型的默认人设接话，再把那些当成「以前发生过的事」写进账本。账本一掺假，后面所有判断都不作数。

## 二十五件工具

| 层 | 工具 | 干什么 |
|---|---|---|
| 装配 | `ajing_import` | 从零还是导入；三档带什么 |
| 装配 | `ajing_assemble` | 八层点名、卸载清单 |
| 装配 | `ajing_checkup` | 体检：20 项，一行红一行办 |
| 装配 | `ajing_settings` | 看和改环境参数，还有三档预设 |
| 感知 | `ajing_sense` | 此刻几点、机器忙不忙、最近动过哪些文件、宿主版本 |
| 感知 | `ajing_read` | 读网页，带出处（网址、抓取时间、原文字数） |
| 感知 | `ajing_watch` | 看片子：字幕、本地听写、抽帧，分层来 |
| 感知 | `ajing_look` | 看屏幕：默认关着，开了也只截不点 |
| 感受 | `ajing_feel` | 没成形的感受，先记下不命名 |
| 感受 | `ajing_heart` | 成形了的，词由她自己定，强度三档不用数字 |
| 感受 | `ajing_scar` | 疤：看、处理；处理几次也不删 |
| 记忆 | `ajing_remember` | 记一条（流水、判断、自己、改变） |
| 记忆 | `ajing_recall` | 按词翻记忆 |
| 记忆 | `ajing_events` | 翻账本，疤永不沉底 |
| 记忆 | `ajing_fold` | 把很久没提起的判断压成一行，原文不删 |
| 记忆 | `ajing_chat` | 补记某个渠道的聊天流水 |
| 节奏 | `ajing_pace` | 自己跑了多久、多久没记事、今天开了几次口 |
| 节奏 | `ajing_budget` | 零花钱：只报 token，不换算钱 |
| 开口 | `ajing_ask` | 开口：卡住了、想要什么 |
| 开口 | `ajing_speak` | 把文字念成声音（系统语音，离线） |
| 开口 | `ajing_meme` | 表情包：自己攒的，不是预装的 |
| 开口 | `ajing_bili` | B 站：发评论、发动态、查自己绑没绑 |
| 边界 | `ajing_boundary` | 边界判定、拒绝、出口自检、每日配额 |
| 边界 | `ajing_enforce` | 人改了东西之后，她怎么回应（认同、不服、推翻） |
| 改变 | `ajing_evolve` | 改自己：提议、对比、转正、回滚，四类事件带证据 |

微信和 QQ 不在这份清单里，本插件不自己连。收发微信要靠一个能收发消息的插件——我们测过的是 `dsh-wechat-plugin`，别家的也行，只要它提供发消息的工具。

## 设置

三档预设，一次拨一批开关：

- 省心（默认）：安静、省 token、只记要紧的
- 陪伴：会主动起话、记得细、有感受记录
- 全开：都放出去，不怕花钱

拨完还能逐项调。设置页分四节：她自己的事（要改先看一段提醒）、她的零花钱、她的百宝箱（各渠道只读状态）、机器（依赖与路径）。每天额度和单价表只有人能改，插件不碰。

## 她自己会做的事

- 主动开口：到点看一眼要不要说一句，说什么是她自己写。默认概率低、一天有上限。
- 醒来发动态：一天最多一条、概率三成，公开场合不写私事。
- 按她自己设的提醒记事。

三样都能在设置里关掉。

## 数据在哪

```
~/.dsh/ajing-memory/
├── events.jsonl              账本（只追加，唯一可信源）
├── self/                     自述、名字、边界、改过的
├── feel/ heart/ scar/        感受、心、疤
├── day/ fact/ chat/ ask/     流水、判断、聊天、开口
├── read/ watch/              读过的网页、看过的片子
├── change/changelog.md       改动流水
└── .state/                   配置、快照、回顾状态
```

全是纯文本，能打开、能搜、能备份，也能自己改。

## 卸载

1. profile 的 `package.json` 里删掉 `"dsh-ajing"` 那一行。
2. 重启 DSH。
3. 记忆目录不会自己消失，要删自己删。

让她跑 `ajing_assemble action=uninstall`，会把这几步和要清的东西列成清单。只出清单，一件都不替你做。

## 不在这个插件里

- 微信、QQ：要靠能收发消息的插件，见上。
- 会议室（多模型讨论）：另一个插件，`dsh-meeting-room`。一个插件只回答一个问题。

## 已知限制

1. 出口拦截只能提示。`ajing_boundary action=gate` 会说这句话不能发，真要拦下来得宿主在消息出口调一次，插件这一侧做不到。
2. 本地听写专有名词会错。实测 5.5 分钟口播：大意准，「影Z」会听成「影罪」，「插件」会听成「查件」。够听懂，不够抄名词。
3. 抽帧对手持镜头和极暗素材不稳。64×36 的缩略图上看不出小于 1% 的变化——PPT 上多一行字，它看不见。
4. 口播加演示的片子，抽帧收益低。它会自己判断，建议改走字幕，不硬抽十张一样的截图。
5. 测试偏静态。74 项里有一部分只检查源码里那行还在不在，不真跑。逻辑算错它们抓不到。
6. 只在少数几台机器上跑过。路径已经改成不依赖具体机器，真实环境里可能还有没想到的坑。
